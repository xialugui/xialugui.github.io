# 流程

硕士毕业与论文息息相关，部分专业需要小论文（需要发表到公开的期刊），大部分专业只要求毕业论文（大论文）。本文不讨论小论文的发表，只关注与按时毕业紧密相关的大论文编写与学位申请流程。

学位论文申请必须通过论文的编写->查重->盲审->答辩->学位申请五个流程，下文将详细描述每个流程的步骤与注意事项，同时还将记录部分同学的问题与解决方案。希望本文能够对各位同学的毕业提供一点点帮助。

> Q1：整个流程最快多久？
>
> A1：最快1周编写 + 1周盲审 + 1周答辩 + 立刻学位申请 = 3周。

## 论文编写

论文编写是整个流程中最耗时的一步，需要认真对待。论文编写通常需要预留至少一个月的时间，这一个月仅能完成初版，后续需要多次修改直至最终版。

### 格式

格式是整个论文的重中之重，格式不正确会影响论文的可读性和（盲）审核通过率。建议严格按照官网提供的格式编写论文，文件从下面的链接获取：

[同济大学研究生学位论文写作参考指南](https://gs.tongji.edu.cn/system/_content/download.jsp?urltype=news.DownloadAttachUrl&owner=1516911423&wbfileid=17835479)

[同济大学研究生学位论文写作参考示例](https://gs.tongji.edu.cn/system/_content/download.jsp?urltype=news.DownloadAttachUrl&owner=1516911423&wbfileid=17835480)

[国务院学位委员会 教育部《研究生教育学科专业目录（2022年）》](https://gs.tongji.edu.cn/system/_content/download.jsp?urltype=news.DownloadAttachUrl&owner=1516911423&wbfileid=14696743)

[GBT 15835—2011 出版物上数字用法](https://gs.tongji.edu.cn/system/_content/download.jsp?urltype=news.DownloadAttachUrl&owner=1516911423&wbfileid=14696741))

[GBT 7714—2015 信息与文献 参考文献著录规则](https://gs.tongji.edu.cn/system/_content/download.jsp?urltype=news.DownloadAttachUrl&owner=1516911423&wbfileid=14696742)

务必仔细阅读文件并按照要求编写论文。

> Q：格式重要吗？
>
> A：工作量（章节与页数达标）+ 格式正确 = 通过盲审。

## 查重

> Q：正式查重之前自己在哪查，是使用知网的个人查重系统吗？
>
> A：*千万不要*使用知网的个人查重系统（贵且不准），使用[学位论文查重系统](https://lwcc.tongji.edu.cn/lw/Check/login)，可在1系统的外部系统中选择跳转。

## 答辩

> Q：答辩是1系统申请吗？
>
> A：答辩在[答辩和学位申请系统](http://myportal.tongji.edu.cn/gsapp2/sys/yjsemaphome/portal/index.do)中申请，可在1系统的外部系统中选择跳转。
